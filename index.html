🔗 Telegram → Crisp Bridge

Telegram → Crisp Bridge — это крупный и высоконагруженный проект, служащий надежным мостом между Telegram и платформой Crisp посредством сложной самописной API-интеграции. Бот добавляется в Telegram-группы через систему интеграций и обеспечивает бесшовное общение чатной поддержки. Проект отлично зарекомендовал себя как крайне стабильное и ценное решение: в интеграцию вовлечено более 1000 Telegram-групп, которые бесперебойно обслуживают 52 оператора в режиме 24/7.

Telegram → Crisp

  • Прослушивание сообщений в группах
  • Автоматическое создание разговоров
  • Проксирование от имени пользователя
  • Поддержка фото, видео, документов, аудио

Crisp → Telegram

  • RTM listener (WebSocket) в реальном времени
  • Отправка в соответствующие группы
  • Поддержка медиа файлов
  • Обработка реакций на сообщения

Надёжность

  • LRU cache для дедупликации
  • Лимит размера файлов (50MB)
  • Ограниченная очередь отправки
  • Автоочистка старых записей

Инфраструктура

  • Webhook режим (мгновенная доставка)
  • Traefik с автоматическим SSL
  • Health check endpoint
  • Docker Compose развёртывание

🔄 TG-Forwarder

Telegram Topic Forwarder Bot — это инструмент для автоматической пересылки сообщений из топиков с определённым названием в единый канал. Бот работает в компании стабильно и приносит значительную пользу, автоматизируя рутинные задачи и уменьшая ручной труд.

Как это работает

  • Автоматическое определение топиков при создании и переименовании
  • Фильтрация: обработка только целевых сообщений
  • Автоответ в исходный топик о принятии запроса
  • Кулдаун (Cooldown) для защиты от спама

Маршрутизация

  • Обычный режим: пересылка в топик Questions to Accounts
  • Режим INR: пересылка в спец-топик, если в названии исходной группы есть "INR"
  • Сохранение контекста и названия оригинальной группы

Инфраструктура

  • Легкая конфигурация через .env файл
  • Полная поддержка Docker и Docker Compose
  • Изолированное виртуальное окружение
  • Скрипты для удобного получения ID топиков

Стабильность

  • Умный кэш топиков (topic_cache.json)
  • Обход Privacy Mode Telegram-групп
  • Управление сессиями Telethon
  • Подробное логирование всех операций

🔍 Monitoring Bot

Monitoring Bot — это Telegram-бот для автоматической маршрутизации сообщений мониторинга. Бот отслеживает сообщения в группе, парсит их, определяет тип и рассылает уведомления в соответствующие группы. Решение обладает высокой стабильностью и автоматическим кэшированием групп.

Парсинг сообщений

  • Тип 1 (Тестовые платежи): Извлекает имена агентов, определяет целевую группу по валюте (MAD, BDT, PKR, KGS, INR) и формирует уведомление.
  • Тип 2 (Отключённые реквизиты): Извлекает имя партнёра и реквизиты, формируя блок-цитату с моноширинным текстом.

Автоматическая маршрутизация

  • Отправка в целевую группу, совпадающую с именем партнёра.
  • Динамическое изучение: бот автоматически запоминает новые группы и сохраняет их в groups.json.
  • Использование HTML-форматирования (blockquote, code) для красивого отображения.

Защита и Алерты

  • Anti-Ban: Предотвращение блокировки (бот не пишет в неизвестные группы).
  • Оповещения об ошибках в специальную алерт-группу с полным текстом ошибки и именем группы.
  • Полное логирование и удалённая отладка (debug_remote.py).

Деплой и Инфраструктура

  • Docker + Docker Compose для изоляции и простого запуска.
  • Деплой одной командой: python deploy.py автоматически подключается по SSH, обновляет код и пересобирает контейнер.
  • Юнит-тесты на pytest для стабильности парсинга.

🚀 VibeVPN — Платформа для приватного VPN

VibeVPN — это полностью автоматизированное решение для запуска собственного премиум VPN-сервиса. Построенный на базе передового ядра Xray-core (VLESS-Reality / VLESS-TLS), проект обеспечивает стабильное и надежное соединение в любых условиях сетей, сохраняя невероятную скорость и минимальный расход заряда батареи на устройствах.

Надежный протокол

  • Использование Xray-core (xtls-rprx-vision) маскирует трафик под обычный HTTPS.
  • Глубокий анализ трафика (DPI) и ограничения сетей остаются в прошлом.
  • Бесперебойный доступ к нужным ресурсам с любого устройства.

Полная автоматизация (Telegram-бот)

  • Клиенты могут сами покупать тарифы, продлевать подписки и получать ключи настройки прямо в Telegram в 2 клика.
  • Удобная система нотификаций и поддержки пользователей.

Богатый выбор платежных систем

  • YooKassa (банковские карты РФ, СБП).
  • Cryptomus (криптовалюты, автоматический процессинг).
  • Lava.top, RuKassa, CryptoCloud.

Мощная Админ-панель и Мульти-гео

  • Управление серверами через красивый и быстрый веб-интерфейс на FastAPI.
  • Отслеживание статуса подписок, создание промокодов и мониторинг трафика в реальном времени.
  • Поддержка балансировки нагрузки между несколькими серверами (Финляндия, Германия и др.).
  • Умный SNI Мультиплексинг с Nginx.

Фабрика Ботов (Managed Bots)

  • Ваш ИИ умеет создавать других ИИ!
  • Автономное развертывание новых, полностью изолированных Telegram-ботов через кастомный API-мост.
  • Назначение уникальных ролей и задач для созданных ботов.

Безграничные Интеграции & API

  • Интеграция передовых моделей (Gemini 3.1, Claude 4.5, DeepSeek V3, Codex).
  • Управление пользовательскими Telegram-аккаунтами (Userbot).
  • Подключение email, трекеров задач и любых внешних API.
  • Нативный Стриминг: текст от ИИ печатается в реальном времени с нулевой задержкой.

Память и Архитектура

  • Векторная Память (RAG): Семантический поиск на базе SQLite vec0 для запоминания контекста.
  • Перехватчики трафика: Кэширование сгенерированного кода в Nginx.
  • Динамические патчи: Модификация ядра OpenClaw "на лету" (JS-патчи).
  • Развертывание: Оптимизация под легкие Ubuntu ARM64 VPS (Nginx + Node.js).

Технологический стек

OpenClaw Node.js Telegram API (Userbot & Bot) Nginx SQLite (vec0) React / TailwindCSS
